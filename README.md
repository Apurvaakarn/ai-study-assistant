# AI Study Assistant

## 📌 Project Overview
AI Study Assistant is a chatbot-based web application that helps users get answers to study-related questions through an interactive interface.

The project demonstrates frontend-backend integration using Flask APIs and a simple AI-style response system.

---

## 🚀 Features
- Interactive chatbot UI
- AI-style responses
- Frontend-backend integration
- REST API communication
- User-friendly interface

---

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python Flask
- Flask-CORS

---

## ⚙️ How to Run the Project

### 1. Open Backend Folder

```bash
cd Backend
```

### 2. Install Packages

```bash
pip install flask flask-cors
```

### 3. Run Flask Server

```bash
python app.py
```

### 4. Open Frontend

Open `index.html` in browser.

---

## 💡 Working

1. User enters a question.
2. Frontend sends request to backend.
3. Backend processes question.
4. AI-style response is displayed.
